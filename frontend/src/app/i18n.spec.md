# i18n.spec.ts

Modified: 2026-11-22

The checks of FE_S11_01 ([frontend.md#languages](../../../docs/backend/frontend.md#languages)).

## The locale files

- `keys(tree)`: every key of a locale file as a dotted path. Each of `de.json` and `es.json` has exactly the keys of `en.json`, so a missing or extra key fails.
- Every entry of `backend/contract/menu.json` has a `menu.<key>`.
- `LANGUAGES` offers English, German, and Spanish, each by its own name.

## The templates

- `templates()` lists every `.html` under `src/app` except `PENDING`, the screens `FE_S11_04_frontend-screen-strings` still moves to keys.
- `literals(template)` is the words a template shows as they are: its text outside comments, `{{ }}`, tags, and control flow (`@if`, `@for`, ...), plus a written-out `label`, `title`, `message`, `placeholder`, `aria-label`, or `alt` (`READ_ATTRIBUTES`). Any word with a letter fails, except `ALLOWED` (the game's name).
- The templates are read with `node:fs`, imported at run time (`await import(NODE_FS)` with `@vite-ignore`): the app has no Node types, and Vitest runs on Node. `FileSystem` types only the two calls it uses.

## The language

- `startLanguage`: saved, else the browser's if offered, else English.
- `translate`: a key, its values, and the English fallback for a code not offered.
- A switch re-renders a menu, sets `<html lang>`, and is saved.
- The language select lists the languages and sets the locale; the settings screens follow a switch.
