# i18n.ts

Modified: 2026-11-22

The app's own text in the viewer's language (FE_S11_01). The rules: [frontend.md#languages](../../../docs/backend/frontend.md#languages).

## `I18n`

- One i18next instance (`i18next.createInstance()`), not the global one, with `en.json`, `de.json`, and `es.json` from `../locales/` bundled as resources, so a static build needs no fetch.
- `init` runs with `initAsync: false`: with bundled resources it is synchronous, so the first render already has its text.
- `interpolation.escapeValue: false`: Angular escapes what a template shows, so i18next must not escape it again.
- `language` is a `computed` over `AppContext.locale`: the chosen code if it is offered, else `FALLBACK_LANGUAGE` (English).
- An `effect` calls `changeLanguage` and sets `<html lang>` whenever `language` changes.
- `translate(key, values)` passes `lng: this.language()` on every call. Reading the signal there is what makes a template or a `computed` that calls it re-render on a switch. A key the language lacks falls back to English (`fallbackLng`).
- `Values` are the `{{name}}` placeholders a key fills in.

## `TranslatedTitle`

A `TitleStrategy` (provided in `main.ts`): a route's `title` is a locale key, and the page title is that key translated. `updateTitle` keeps the key; an `effect` on `language` sets the title again after a switch, without a navigation.

## The language list (`context.ts`)

- `LANGUAGES`: the offered languages, each `{ value, label, flag }`: the code, the name in its own language (English, Deutsch, Español), and the flag-icons code its picker shows (`us`, `de`, `es`; [language-select.md](ui/language-select.md)). A new language adds its locale file and its entry here ([who reviews](../../../docs/backend/frontend.md#languages)).
- `FALLBACK_LANGUAGE`: `en`, for a missing key and when nothing else fits.
- `offeredLanguage(code)`: the offered language a code names (`de-DE` names `de`), or `null`.
- `startLanguage(saved, browser)`: the saved one, else the browser's (`navigator.language`) if offered, else English. `AppContext.locale` starts from it.
