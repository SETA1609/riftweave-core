# Player and GM guide

How to sit down and play Riftweave at a table with dice and paper. The [core rules](../core/) and [modules](../modules/) are the reference; these pages are the short way in.

- [Quick start](quick-start.md): make a character, take a turn, run an encounter.
- [Running the game](gm.md): pacing, difficulty, and ruling on anything the rules do not list.

You need percentile dice (two d10s), the usual polyhedral dice for damage, and a grid if you like one. One square is one unit, about 1.5 m.
