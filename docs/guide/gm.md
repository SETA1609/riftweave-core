# Running the game

## Pacing

- **Keep it moving.** A turn is a few AP and one roll. If a player is stuck, ask what they want to happen, then name the action that does it.
- **Time in turns only when it matters.** One turn is 5 seconds. Outside a fight, count minutes, hours, or days.
- **Rests are a choice with a cost.** A short rest is an hour and a long rest a night. Let the world move while the party sleeps.
- **Hand out levels by story or by XP.** XP awards are guidance and not a rule. Level 2 takes 900 XP, and each level after takes more.

## Choosing opponents

Every monster has a level. These are what a fair fight looks like at each band:

| Levels | Damage per hit |
| --- | --- |
| 1–5 | 4–7 |
| 6–14 | 7–12 |
| 15–20 | 10–16 |
| 21–30 | 14–22 |

Monsters are built to take a set number of hits at that damage: a **minion** 1–2, a **standard** monster 4–6, and a **boss** 8–12. To make a fight harder, add monsters or raise their level before you add a boss.

## Difficulty

A task has no difficulty number of its own. You add a bonus or a penalty to the skill, and the player rolls.

| The task is | Modifier |
| --- | --- |
| Routine, under pressure | +30 |
| Easy | +20 |
| Fair | 0 |
| Hard | −20 |
| Very hard | −40 |

These steps are a suggestion. A skill of 50 is a trained professional, and a Fair task should succeed about half the time for them. Do not roll when failure would not change anything.

**Use the margin.** It is how well something went. A wide margin can mean a job done faster, more information, or less noise. On a failure there is no margin, so decide what the failure costs.

**Opposed rolls.** When two people pull against each other, both roll, and the higher margin wins. A failure loses to any success, and the defender wins ties, as with a dodge.

## Ruling on what the rules do not list

Everything goes through the one roll.

1. **Name the skill.** If two fit, take the one the character is better at, or the one the method suggests. Climbing a wall is athletics, and talking the guard into opening it is persuasion. The [checks](../core/checks.md) list common uses.
2. **Set a bonus or penalty** from the table.
3. **Say what failure costs before the roll.** Time, noise, a wound, or a closed door.
4. **Roll once.** A second try needs something new to change the odds.

If no skill fits, use an attribute: its value × 10 is the target.

**Damage you have to invent.** Use the band for the party's level: a falling crate is about what a monster of that level would deal. For a fall, roll the same way, and let armor help only if it would.

**Conditions you have to invent.** Pick the nearest [condition](../modules/conditions.md) instead of writing a new one. A held-down character is restrained, and a dazed one is staggered.

**What happens at 0 HP.** The core rules leave this to you. A simple default: at 0 HP a character is down and out of the fight, and an ally can bring them round with healing or a short rest. Decide before the first fight, and tell the players.

## Being fair

- **Roll in the open** when you can. Rolls are inputs to the rules, so everyone can check a result.
- **Say the stakes.** Players choose better when they know what they risk.
- **Change a ruling once, then write it down,** so the same case goes the same way next time.
