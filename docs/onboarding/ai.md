# AI rules

1. **AI is welcome as a tool.** You may use AI assistants and coding agents to write, edit,
   and check anything in this repository.
2. **A human always reviews before committing.** Nothing is committed until a person has
   read the whole change.

Reviewing means reading the actual diff and understanding it, not only checking that
validation passes. The person who commits is responsible for the change, whoever or whatever
wrote it.

An agent working in this repository follows the same rule: it commits only when a person
asks, and only after that person has reviewed the change. [AGENTS.md](../../AGENTS.md) has
the other rules for agents.
