## S26 A resource API guide

**Goal:** One written guide says how the API should look before any more endpoints are built: the resources a person works with (rules, characters, creation drafts, the profile, saved games, encounters, the bestiary, settings, files, authoring), each endpoint with its method, path, purpose, and the core command that holds its rule, without code. Every later endpoint issue follows it, and the HTTP server and the browser keep one shape for every resource.
