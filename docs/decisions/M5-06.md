# M5-06 Entry docs and review archive sync

Date: 2026-11-09

- **Decision:** which document wins is written once, in `CONTRIBUTING.md#which-document-wins`:
  `docs/core/` over `docs/modules/`, the golden vectors over an implementation, and
  `docs/archive/` decides nothing. **[V 2026-11-09]**
- **Decision:** `plan.md`, `issues.md`, and `docs/review/` move to `docs/archive/`. Frozen logs
  (`docs/decisions.md`, `done.md`, `CHANGELOG.md`) keep the old paths. **[V 2026-11-09]**
- **Decision:** `docs/core/overrides.md` wins over `docs/modules/module-system.md` and
  `AGENTS.md`: a module overrides a core row only by listing its key in `overrides`.
  **[V 2026-11-09]**
- **Why:** the entry docs described an early layout, milestones marked as not started, and
  three different override rules.
- **Open:** `module_loader.merge_data()` does not read `overrides` yet and flags every
  duplicate as a conflict; the rule and the manifest field exist, the loader does not
  follow them. **[V 2026-11-09]**
- **Risk:** files in `docs/archive/` may link to paths that have since moved; they are kept
  as written.
