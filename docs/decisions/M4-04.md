# M4-04 Traps and environmental hazards

Date: 2026-11-06

- **Decision:** a hazard is a row in `ruleset/data/hazards/core.json`: a trigger, a damage
  packet and effects, a detect check, a disarm check (traps only), and an optional avoid check
  (`on_avoid` `none` or `half`). Every check is one call of the resolution function through a
  check row, with the hazard's difficulty as an `add` on the target. A trigger emits one packet
  and the effect list; the consumer applies DR, resist, and conditions. Twelve hazards (nine
  traps, three environment), 14 vectors. Spec: `docs/core/hazards.md`. **[V 2026-11-06]**
- **Decision:** `core:check/<key>` is now a checked reference category in `validate.py`, and
  `poison_weakness` loses its `reserved` flag, since the poison needle uses it. **[V 2026-11-06]**
- **Why:** hazards existed only as a backlog line.
- **Open:** a disarm fumble triggers the trap; a detect fumble is only a failure **[A]**. A
  trigger without an avoid roll always lands **[A]**. Hazard damage by level has no balance band
  yet (M4-05) **[U]**.
- **Checked:** the Go core runs all 270 vectors, the 14 `hazard` ones included, and its command
  list matches the contract. **[V 2026-11-06, `go test ./...` in `backend/`]** An unknown op is
  a rule error in Go (`hazard op "x" is not defined`, a `NotDefinedError`) where the Python
  reference says `op 'x' is not defined`; a check without `roll` is a `MissingInputError` where
  Python raises. No vector names either.
