# M5-18 Alpha playtest through the human CLI

Date: 2026-11-12

- **Decision:** these runs are **agent-played**, not the human playtest the issue asks for. `ruleset/scripts/playtest_driver.py` plays eight builds (melee, ranged, five casters that together cover the nine colors, and a spellblade) from creation to level 30 through the agent CLI's `session` command, with seeded rolls in each step's input. All eight saved sessions (`docs/playtests/sessions/`) reach level 30 and replay to the same actor. The issue stays `doing`: the human pass through `riftweave play` still has to run, and it can start from these builds. [V 2026-11-12, `session replay` on each file]
- **Decision:** each finding is an issue or a decision ([docs/playtests/README.md](../playtests/README.md#findings)): APP-12 (a session cannot record skill ranks, perks, or spells), APP-13 (a session never applies the actor's perks, modifiers, or gear), M3-17 (monster skills do not grow with level), M3-18 (no command applies a cast's damage; three colors have no damaging spell), and M5-50 (skills cap by level 5 to 8; weapon damage does not grow). No run contradicted a vector, so none became one. [V 2026-11-12]
- **Decision:** the XP for each level is set by the driver, since XP awards are GM guidance and not a rule; the runs measure the build, not the XP curve. [A]
- **Why:** the alpha is meant to find what a person has to decide, what never comes up, and where a rule is missing or reads two ways. An agent pass finds the mechanical gaps first, so the human pass spends its time on judgment.
- **Open:** what a person has to decide is not measured by an agent: the driver follows a fixed build plan. The perk tallies below come from that plan (its first-choice perks first, then the first eligible perk by key), so a perk early in the alphabet is over-counted. [A]
- **Risk:** every perk's effect on the runs was nil, because a session does not apply perk modifiers (APP-13). The "what it changes" column is what the perk would change once it does: a `pending` target has no rule that reads it yet.
