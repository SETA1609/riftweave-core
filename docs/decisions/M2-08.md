# M2-08 Luck growth of HP, mana, and stamina

Date: 2026-11-09

- **Decision:** each level-up adds a roll from 0 to `floor(LCK / 2)` to HP, mana, and stamina,
  the rolls are inputs to `level_up`, and the actor stores the sum as `growth`. Stamina is a
  derived row. Spec: `docs/core/progression.md#resource-growth`, `docs/core/derived.md`.
  **[V 2026-11-09, vectors in Python and Go]**
- **Why:** HP, mana, and stamina grew by fixed amounts, and the docs disagreed with the data.
- **Difference from the issue:** `derived.schema.json` did not change; the `sp` row fits it.
- **Open:** the example characters record no pool rolls, so their vectors use 0 and their
  tables keep today's values. The stamina formula `10 + END × 5 + level × 2` is a proposal.
