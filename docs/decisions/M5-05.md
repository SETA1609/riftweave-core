# M5-05 Player and GM guide

Date: 2026-11-11

- **Decision:** the guide is `docs/guide/`: about 1,700 words, well under ten pages, and it links to the rules instead of restating them. The worked numbers were run through the reference. **[V 2026-11-11, `derived`, `combat`, and `progression`]**
- **Decision:** the GM page suggests things the rules leave open: a difficulty table, opposed rolls by margin, an attribute check at the attribute × 10, and being down at 0 HP. Each is advice to a table, not a rule. **[A]**
- **Why:** an SRD needs a way in for a table, and there was no how-to-play text.
- **Open:** the instant-spell save and other rules still on open branches are named only in general terms. **[A]**
