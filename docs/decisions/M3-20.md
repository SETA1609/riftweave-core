# M3-20 Perks raise the number of active summons

Date: 2026-11-14

- **Decision:** the limit lives in `casting`, beside concentration, since both are "a new one ends an old one": the caster's active summons are an input (`caster.summons`, oldest first, one summon group ref per creature), and a cast returns `summons` and `dismissed`. Summoning itself (composing the creature) stays in the bestiary reference. [V 2026-11-14, `casting` vectors in Python and Go]
- **Decision:** the cap counts creatures, so a spell with magnitude N adds N entries. `summon_limit` is 1 in `casting/core.json`; a caster's `summon_limit` modifiers add to it through the kernel's stacking. Past the limit, the oldest go first. A cast that fails, is prevented, or lacks mana changes nothing. [V 2026-11-14]
- **Decision:** two perks, **Retinue** (level 14, Orange or Black Magic 60, needs Conjurer) and **Host** (level 28, Orange or Black Magic 90, needs Retinue), each `add 1` on `summon_limit`, so three at most. [A for the skill gates]
- **Why:** owner request, 2026-11-14: summons need a cap, raised only by perks.
- **Open:** minions (M3-25) will not count toward the limit; until M3-25 adds them, every summon counts. Raise Horde and Conjured Legion still summon three, so without perks a cast keeps only the newest one; M3-25 makes them minions. [A]
