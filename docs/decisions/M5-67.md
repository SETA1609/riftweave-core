# M5-67 Original perk names: rename the ones taken from other games

Date: 2026-11-18

- **Decision:** ten perks get our own key and label, with their rules unchanged: `toughness` → `hardened_hide` (Hardened Hide), `alert` → `ever_watchful` (Ever Watchful), `iron_will` → `unshaken` (Unshaken), `lucky` → `fates_reprieve` (Fate's Reprieve), `quick_draw` → `ready_hand` (Ready Hand), `spell_penetration` → `ward_breaker` (Ward Breaker), `second_wind` → `catch_breath` (Catch Your Breath), `light_foot` → `easy_stride` (Easy Stride), `gunslinger` → `hip_shot` (Hip Shot), `deadeye` → `gap_finder` (Gap Finder). The `second_wind` and `second_wind_hp` modifier targets become `catch_breath` and `catch_breath_hp`.
- **The names** are the issue's proposals [A]; the owner asked for the issue to be done without a separate naming round, and can still change any of them in a follow-up rename.
- **Every ref moved:** prerequisites, builds, the example characters, monster rows and the `dire` and `elder` templates, vectors, Python and Go tests, the build and module docs. The perk ladder and formula pages were regenerated with `data_flowcharts.py --write`, and the playtest sessions and report with `playtest_driver.py`. [V 2026-11-18, `validate.py`, the Python tests, `go test ./...`]
- **The playtest report** matches a fresh run on `development` apart from the names and one total: each build takes the same perks, and the report's tallies are equal, but four caster builds take some perks at other levels, because the driver fills its free picks in key order and a renamed key sorts elsewhere (`iron_will` before, `unshaken` after). That changes the binary's `calls` total (21157 to 21294). [V 2026-11-18, both runs compared after mapping the old keys]
- **Kept on purpose:** plain-English uses of the old words (END as "toughness", "a lucky roll", the frontend's `.alert` component), the racial trait Dwarven Toughness (a racial trait, not one of the ten perks; left for a later look [U]), and history (`docs/decisions/`, `docs/issues/done/`, `CHANGELOG.md`).
- **A list of names not to use** is in CONTRIBUTING.md (Naming), with `power_attack`, `cleave`, and `duelist`, which M3-28 and M3-29 rename.
- **Risk:** a rename is breaking for saved characters and sessions outside this repo that name an old key; nothing here migrates them.
