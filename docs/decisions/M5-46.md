# M5-46 Spell out op and the formula tree's short names

Date: 2026-11-12

- **Decision (formula trees, part 1 of 3):** a formula tree reads `operation`, `arguments`, `literal`, `attribute`, `variable`, and `expression`, and the operation values are spelled out too (`subtract`, `multiply`, `divide`; `add` stays), as the owner chose on 2026-11-12. The action pool and derived rows name `attribute` and `per_level_attribute`, and the luck roll `max_attribute`, since `attr` is the same abbreviation. Modifiers and commands keep `op` until parts 2 and 3; until then two names for one concept coexist. [V 2026-11-12, `formula` vectors in Python and Go]
- **Decision (modifiers, part 2a of 3):** every modifier in the data names `operation`, and `mul` is `multiply`; the other operation names (`add`, `set`, `grant`, `resist`) are already words. The vectors and the command contract keep `op` for one more pull request, so the Python and Go readers accept both names until part 2b renames the vectors and drops `op`. [V 2026-11-12, `validate.py`, the tests, and `go test`]
- **Decision (modifiers, part 2b of 3):** the vectors, the contract's running modifiers, and every emitted modifier name `operation`; the schemas, the references, and Go read only `operation`, so the dual reading of part 2a is gone. [V 2026-11-12]
- **Decision (commands, part 3 of 3):** the `progression`, `economy`, `hazard`, and `spellcraft` commands take `operation`, as `session` already did (APP-04); a contract file names its `documentation`; `damage_mul` is `damage_multiplier`, `effect_magnitude_mult` is `effect_magnitude_multiplier`, and an item instance's `mods` is `added_effects`, since they are applied effects. `doc`, `damage_mul`, and the `attr` family were not in the issue's list but are the same abbreviations, so its done-when covers them. No data, schema, contract, or vector key is one of the old names. [V 2026-11-12, a key scan of `ruleset/` and `backend/contract/`]
- **Open:** `cp` and `gp` in keys (`price_cp`, `scroll_gp_per_mana`) are currency units, which the naming rule allows in a name when the number is not in the neutral unit; `skill_ok` and the local Python names (`eff_mag_mult`) are left. [A]
- **Risk:** every consumer of the JSON breaks at once across the parts; a client written against the old names must rename `op` on modifiers and commands, the formula keys, and the four renamed fields.
