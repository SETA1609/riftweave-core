# M5-31 File the data model review

Date: 2026-11-10

- **Decision:** the data model stays as `docs/core/data-model.md` defines it: relational in its
  logical design, stored as JSON documents, loaded into flat tables. The review found no reason
  to change the type, only places where the data does not follow it, filed as M5-32 to M5-41.
- **Why:** each finding passes `validate.py` today (45 of 45 files), so only an issue keeps it
  from being forgotten. **[V 2026-11-10]**
- **Findings, as counted on `main` at `faf2057`:** **[V 2026-11-10, a script over every file in
  `ruleset/data/` and `ruleset/modules/`]**
  - Modifiers name 145 distinct targets; 92 are a key in no table (M5-32). 29 `add` modifiers
    carry a percentage in the target name, and `safe_fall_meters` and `darkvision_range` hold
    metres where the contract says units (M5-33).
  - `combat/base_resolution.json` repeats the crit window, fumble, crit damage, AP pool, and
    action costs, and keeps a `videoGame` block. `combat_reference.py` reads it and rolls a
    second d100 to confirm a crit; the Go backend does not (M5-34).
  - 14 features state a bonus in both `effects` and `modifiers` with different targets; 10
    creation traits state theirs only in `effects` (M5-35).
  - A monster `base` is a bare name or a `core:monster/` reference in the same field; equipment
    `base` and `default_materials` are bare names (M5-36).
  - `abilities`, `sp`, `block`, and the target `attack` each name two concepts; called shots
    are spelled two ways (M5-37).
  - The actor the backend reads has attributes, skills, level, and growth only, and no session
    schema exists yet (M5-38).
  - `contract.md` and `data-model.md` disagree with the data in four places (M5-39).
  - 72 `camelCase` and 85 `snake_case` property names (M5-40).
  - 54 equipment rows only repeat their base's key (M5-41).
- **Open:** whether M5-32 to M5-41 block `v1.0.0` (M5-09's `Needs`) is the owner's call; this
  issue does not add them. M5-38 is added to APP-04's `Needs`, since APP-04 stores the actor. [A]
- **Risk:** M5-33, M5-35, M5-36, M5-37, and M5-40 rename or remove keys and break consumers.
