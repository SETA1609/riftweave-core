# M2-06 Gated block and dodge perks

Date: 2026-11-06

- **Decision:** two perk ladders, each rung gated by a skill threshold, a tier, and the rung
  below. Block: Shield Training (`add shield_dr 2`), Spell Ward (`grant block_magic`),
  Bulwark (`grant bulwark`). Dodge: Sidestep (`add dodge -1`), Armored Evasion
  (`add evasion 10`), Riposte (`grant riposte`). Spec: `docs/core/combat.md#block-and-dodge-perks`.
  **[V 2026-11-06]**
- **Decision:** the perks reach combat as a new `defender.modifiers` input: adds on the
  reaction targets (`evasion`, `block`) and on `shield_dr`, stacked by `modifier.md`, and
  grant flags read with the kernel's flag rule. The grants are not merged into
  `defender.flags`, so they do not trigger situation rows. **[A]**
- **Decision:** Spell Ward lets a block stop a single or area attack of any type, at half the
  shield DR rounded down; the shield's own number scales it, not a `resist`. Bulwark sets
  damage to 0 on a block tagged `crit`, after the shield step; the hit still counts, so
  riders are listed. Riposte sets a new `counter` result on a crit evade of a single attack;
  the caller runs the counter-attack. **[A]**
- **Decision:** an instant attack still takes no reaction with every perk. A vector holds
  every block perk and a crit block roll against an instant fire attack, and another every
  dodge perk. **[V 2026-11-06]**
- **Decision:** "cheaper dodges in armor" is Sidestep, `add dodge -1` on the action's key, and
  the actions function now reads `add` modifiers on each action key (never below 0). The AP
  rules have no armor surcharge, so the cheaper dodge holds in any armor; Armored Evasion is
  the in-armor rung, offsetting the armor penalties on the evade target. **[A]**
- **Why:** after M1-02 an evade avoids everything and a block only subtracts shield DR; the
  issue balances them with perks, not pipeline changes.
- **Checked:** 14 combat and 3 actions vectors pass in Python and Go, and every older vector
  still passes. **[V 2026-11-06, `go test ./...` in `backend/`]**
- **Open:** armor evasion penalties are still not modifiers anywhere, so Armored Evasion
  offsets nothing in a vector yet **[U]**. The older Shield Wall perk (`block_percent`) has
  no pipeline step **[U]**.
