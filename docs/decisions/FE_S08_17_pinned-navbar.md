# FE_S08_17_pinned-navbar A navbar pinned on top, with a burger menu on mobile

Date: 2026-11-27

- **Decision:** `rw-navbar` replaces the shell's header: the name home (kept as the page's `h1`), the language select, the theme toggle, and the GitHub link; sticky on top; under 768px the three items fold into a burger dropdown [V 2026-11-27, e2e at 1024px and 375px over both transports].
- **The package:** `@fortawesome/free-brands-svg-icons` 7.3.1, pinned exactly, the same version as the solid set (published 2026-07-15) [V 2026-11-27, `npm view`]. Font Awesome's free icons are CC BY 4.0; the attribution is the license comment the package keeps in its files, and the bundle keeps third-party license comments [A: to confirm in the licensing audit, PO_S01_01]. GitHub's logo is used only to link to the repository [A].
- **Escape:** closes the dropdown and stops there while it was open, so with FE_S08_12's screen header (Esc goes back) one Escape does one thing [V 2026-11-27, unit spec]. The header listens on the document; the navbar on its own element, which has focus after the burger is clicked [A].
- **Sticky, not fixed**, so nothing hides under the bar and no padding has to match its height [A].
- **Later, its own issue:** a donations link in the same navbar (from the issue).
- **The Stitch layout** (owner, 2026-11-27): the bar follows the mockups (docs/design/mockups/, 2026-11-23), which are newer than the issue's first text (2026-11-22). The burger now opens the navigation, the main menu of `menu.json` and GitHub, and the language and the theme stay in the bar at every size, as the mobile mockup has them; the issue text says so now [V 2026-11-27, screenshots at 320, 375, 768, 1024, and 1280px].
- **Breakpoints by flex, mobile first:** 320px is the base; 768px adds the rules version and the playing chip; 1024px puts the main menu inline and hides the burger. The brand gives up room first on a phone (its name shrinks with `clamp`), the playing chip first from 1024px, so the menu shows whole in en, de, and es [V 2026-11-27, e2e on six device sizes and German at 1024px]. In German at 1024px the chip keeps about 49px; the side navigation (FE_S22_05) frees that room later [A].
- **Dropped or later:** the mockups' status chip (owner, 2026-11-27); the profile avatar, until a profile exists (FE_S25_07); the side navigation and the bottom tab bar (FE_S22_05). Until FE_S22_05, the main menu shows inline from 1024px in place of the side navigation [A].
- **Touch targets:** the bar's controls are the language select's and the theme toggle's own buttons, so their size is a global rule scoped to `rw-navbar` in `styles.css`, not `::ng-deep`, which Angular deprecates and the app does not use [A].
- **Tests changed:** the language spec reads the compact code (`DE`); the character list spec clicks Characters in the home menu, now that the navbar has the link too; the rules-version check reads the footer, now that the navbar shows it too.
