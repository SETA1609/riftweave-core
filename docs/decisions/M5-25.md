# M5-25 Game state is a snapshot and a log

Date: 2026-11-10

- **Decision:** the ruleset and a running game have separate models. A session is a ruleset
  version, a starting actor, a log of commands, and the current actor as a cached result.
  Spec: `docs/core/state.md`. **[A]**
- **Why:** APP-04 was about to define the shape of game state with no spec, and rolls being
  inputs makes a replayable log cheap.
- **Open:** checkpoint rules and the schema are settled when APP-04 is built. **[A]**
