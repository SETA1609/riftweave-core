# M5-22 Move fetch-docs to devops-tools

Date: 2026-11-09

- **Decision:** `devops-tools fetch-docs` replaces `tools/fetch-docs/`; `docs-cache-directory`
  is `cache/docs`. **[V 2026-11-09, a README from GitHub and a page by URL downloaded into
  `cache/docs/`]**
- **Why:** the same downloader lived in two repositories.
- **Difference from the issue:** the docs pass `--cache-directory cache/docs`. At the pinned
  commit, `fetch-docs github` without it crashes, because its `repository` argument and its
  `--repository` option share one name. **[V 2026-11-09]** The fix belongs in `devops_tools`.
- **Open:** drop `--cache-directory` from the docs once a fixed devops-tools is pinned.
