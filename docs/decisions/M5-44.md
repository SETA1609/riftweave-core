# M5-44 Weight has a neutral unit

Date: 2026-11-11

- **Decision:** every weight is in weight units: an item's `weight`, a material's `weightFactor` applied to it, the `carry` limit, and the encumbrance thresholds. One weight unit reads as 0.5 kg (500 g) at a table; nothing stores the conversion. Spec: `docs/core/contract.md#weight`, beside distance. **[V 2026-11-11, `test_modifier_units.py`]**
- **Decision:** no row changes. Today's numbers were pounds (0.454 kg), so reading them as weight units moves them by about 10%. The `carry` row's `unit` is `weight_units`. **[A]**
- **Decision:** a name carries a unit only when the number is not in the neutral unit for its kind (units, seconds, weight units); `CONTRIBUTING.md#naming` no longer gives `range_meters` or `weight_kilograms` as examples.
- **Why:** distance and time had a neutral unit and one conversion; weight was the last value written in an imperial unit.
- **Open:** whether 0.5 kg reads well for the heaviest rows (plate, tower shield) is untested in play. **[U]**
