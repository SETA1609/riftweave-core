# M5-15 One file per decision

Date: 2026-11-04

- **Decision:** decisions move from one shared log to one file per issue,
  `docs/decisions/<issue-id>.md`. `docs/decisions.md` is frozen as the log up to 2026-11-04;
  links to it stay valid.
- **Why:** every pull request inserted its section at the top of `## Decided`, so any two open
  pull requests conflicted there. `keep-both-added-lines` resolves that only inside the rebase
  workflow, which runs after a push to `main` and only for branches with an open pull request;
  GitHub's merge button ignores custom merge drivers. Checked with real merges on 2026-11-04: 5
  of 7 open branches conflicted with `main` in `docs/decisions.md`, and every pair conflicted
  after one merged. **[V 2026-11-04]** A new file per issue never conflicts.
- **Open:** the old log's open questions and risks stay where they are until an issue settles
  them; that issue records it in its own file. **[A]**
