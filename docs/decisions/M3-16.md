# M3-16 Natural weapons are unarmed attacks

Date: 2026-11-14

- **Decision:** the `natural_weapons` table stays, and the file names the one skill every row rolls with, `skill: core:skill/unarmed`, so the rule is written once and a module's natural weapon follows it. A carried weapon rolls with its own row's `skill`. [V 2026-11-14, `test_bestiary.py`]
- **Decision:** the unarmed perks change an unarmed attack through the kernel's modifier steps (`kernel_reference.apply_modifiers`): `unarmed_damage` adds after the dice, the attribute modifier, and the growth bonus, then `unarmed_strike_damage` multiplies, floored. A jaguar's claw rolling 4 with AGI 8 deals 7, 9 with Brawler, and 13 with Brawler and Iron Fist; a sword takes neither. [V 2026-11-14, `test_bestiary.py`]
- **Decision:** a row with no attack and no damaging ability attacks with `core:natural_weapon/slam` on `str`. No row in the data needs it today, since `validate.py` requires an attack or a damaging ability; the default is for generated and module creatures. [A]
- **Decision:** a feature's `natural_weapon` is a `core:natural_weapon/<key>` ref **(breaking)**, and its dice move by the actor's size on the creature size steps. A player's size is its race's `size`, so a medium catfolk claws for 1d6 as a medium jaguar does. [A]
- **Why:** owner question, 2026-11-12: whether monsters without weapons should just make unarmed attacks with feats. A feat per attack type would repeat the table, so the table stays and the attacks become unarmed.
- **Open:** `unarmed_damage` and `unarmed_strike_damage` stay `pending` in `modifier_targets`: the `combat` command (Python and Go) does not read them yet, only the bestiary reference does, and `validate.py` ties `pending` to the golden vectors. A combat issue that reads an attack's skill and these targets turns them into vectors. The issue listed `validate.py`; it needed no change, since the generic ref check already resolves a feature's `natural_weapon`.
- **Risk:** a monster's to-hit is now `unarmed`, which M3-17 grows with level like any combat skill, so nothing changes for monsters; a player's natural weapon now needs points in `unarmed` to hit.
