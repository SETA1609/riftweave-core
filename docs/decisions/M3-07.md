# M3-07 Cast cost by skill and perks

Date: 2026-11-09

- **Decision:** the paid cost is the skill discount, rounded up, then the modifiers on
  `spell_cost`, at least 1. Spec: `docs/core/casting.md#paid-cost`. **[V 2026-11-09, casting
  vectors in Python and Go]**
- **Why:** every caster paid the authored cost whatever their skill.
- **Difference from the issue:** it says the result is rounded up. The discount is rounded up,
  but a `mul` on `spell_cost` floors, because modifiers stack by the kernel rules and one rule
  for every target beats a special case here. It is worth under one mana.
- **Difference from the issue:** the level vector is one case, since the cast takes no level
  input; level cannot change the cost.
- **Vectors changed:** the existing casts now spend the discounted cost (fire bolt at red
  magic 50 pays 5, was 6), as this rule requires.
- **Open:** no perk or item emits `spell_cost` yet. **[V 2026-11-09]**
