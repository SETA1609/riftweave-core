# M3-01 Casting procedure: decide scope, then specify

Date: 2026-11-06

- **Decision:** a cast is one call of the resolution function on the spell's `<color>_magic`
  skill. The gate (a `prevented_by` flag), the mana cost, and the reagents come first, and a
  gate that fails spends nothing; the cost is spent before the roll, so a failed cast still
  costs it. A success emits the spell's effects at their authored magnitudes. Spec:
  `docs/core/casting.md`; coefficients: `ruleset/data/casting/core.json`; 22 vectors in
  `ruleset/tests/vectors/casting.json`, in Python and Go. **[V 2026-11-06]**
- **Decision:** components are core as reagents only (`cost.reagents`, consumed by the cast).
  Verbal and somatic components are cut; `silenced` now blocks every cast, and the silence
  effect and the silenced condition say so. **[V 2026-11-06]**
- **Decision:** concentration is core: `concentration: true` on a spell. A caster holds one; a
  new one ends the old, a failed one ends nothing. `blessing` and `ward` are concentration
  spells. **[V 2026-11-06]**
- **Decision:** dispel is core: the `dispel` effect, magnitude N, ends every standing spell of
  level N or below. Spells gain a required `level` (1 to 30), and `dispel_magic` (violet,
  level 4) is the first row. The cast returns the dispelled keys; the consumer removes their
  `spell:<key>` modifiers through the removed sources of `modifier.md`. **[V 2026-11-06]**
- **Decision:** spell failure from armor is core as a penalty, not a failure chance: the
  heaviest armor category worn adds `none` 0, `light` 0, `medium` -10, `heavy` -25 to the cast
  target, as an `add` with source `armor:<category>`. **[A]** for the numbers.
- **Decision:** counterspell is cut, since there is no reaction slot (`actions.md`). Ritual
  casting is not core; it is a module after 1.0. **[V 2026-11-06]**
- **Decision:** scaling a magnitude by the margin (the old `magic.md` §4 step 3) is not core.
  The margin is in the result for a consumer that wants it. **[A]**
- **Why:** the issue asks for each mechanic as core, module, or cut, with the core ones as
  data. Each core one reuses a function that exists: resolution for the check, modifiers for
  the armor penalty and for removing dispelled spells.
- **Open:** the incapacitated and unconscious conditions say no concentration is possible,
  but nothing ends a held spell when they apply; the consumer drops it **[A]**. A fumble is
  only a tag on a failure **[A]**. Spell delivery and saves stay with M3-05, and the trap
  spells with M3-02 **[U]**.
- **Checked:** Python and Go agree on all 22 casting vectors, the three errors included
  (`spell "nope" is not defined`, a `NotDefinedError` in Go; `casting fire_bolt needs
  red_magic`, a `MissingInputError`). An unknown armor category is an error in both; no
  vector names it. **[V 2026-11-06, `go test ./...` in `backend/`]**
