# M5-29 The key is the only row identity

Date: 2026-11-10

- **Decision:** a row's identity is its `key`. A vocabulary row with no key falls back to its
  string `id`. Spec: `docs/core/keys.md`. **[V 2026-11-10, `test_module_system.py`]**
- **Why:** references already rejected numeric ids, and 14 of the 35 keyed tables had none.
- **Check:** a script removed only integer `id` fields and compared every file before and after.
  **[V 2026-11-10]**
- **Difference from the issue:** three module tests expected conflicts by numeric id and now use
  keys; that is the change this issue makes.
