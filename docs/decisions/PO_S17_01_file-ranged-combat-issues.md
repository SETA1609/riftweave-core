# PO_S17_01_file-ranged-combat-issues File the ranged combat issues

Date: 2026-11-18

- **Decision:** a new story, S17 Ranged combat, holds the ranged work: ammunition and the reload action (`GD_S17_02`), grenades (`03`), elemental bolts and bullets (`04`), the ranged full attack (`05`), ranged maneuvers (`06`), the bow, firearm, and crossbow-and-thrown ladders (`07` to `09`), ammunition scavenging perks (`10`), bound ranged weapons and Bound Ammunition (`11`), the rework of the ranged builds (`12`), and the ranger's switch and mixed-hand ladders (`13`). The extra-strike ladder of `GD_S05_01` now names any weapon, melee or ranged. (Owner request, 2026-11-18.)
- **Ammunition and grenades come first:** no ammunition item, no `reload` action, and no grenade exist today (`fast_reload` changes a `reload_cost` that no action has) [V 2026-11-18, `actions/core.json`, `equipment/`]. Elemental rounds are defined against grenades, and the bound ammunition, the scavenging perks, and the maneuvers spend rounds, so `02` and `03` have no `Needs` and the rest follow them.
- **A weapon is told apart by its properties, not its key** [A]: longbow = bow with `heavy`; pistol = gun with `light`; blunderbuss = gun with a new `scatter` property; hand crossbow = crossbow with `light`. A perk prerequisite names the held weapon by skill and properties, added once in `07`.
- **The ranger has two forms** (owner 2026-11-18): the switcher changes between a ranged and a melee weapon, and the mixed hand holds a one-handed melee weapon with a pistol, a hand crossbow, or a light thrown weapon. `05` adds the mixed-hand loadout row; `13` adds a weapon swap cost, which no rule has today [V 2026-11-18, `docs/core/actions.md`], and a perk line for each form.
- **The ladders run in a chain** (`07` → `08` → `09` → `10` → `11` → `13`): each adds rows to `ruleset/data/features/core.json`, and two ready issues that list the same file conflict ([stories README](../stories/README.md#order)).
- **Bows get no elemental arrows in core** [A]: the owner named crossbows and guns; keeping the bow single-target keeps the paths apart.
- **Open:** whether core adds a rifled long gun or the arquebus is the rifle (`08`); whether the marksman and the breacher are build rows or sections of the gunslinger's page (`12`); whether conjured rounds in a mundane weapon deal `magic` or the weapon's type (`11`, with `GD_S06_01`). Go code for ammunition, bursts, and zones may need `BE` issues once the rules are specified; none is filed yet [A].
- **Not filed:** a ranged defense ladder. M5-61 found none (the arbalist borrows the shield ladder, the archer and the gunslinger the evasion ladder); the owner did not ask for one.
- **Unverified numbers:** every AP cost, penalty, radius, level, and count in the issues is a proposal for the spec step [A].
