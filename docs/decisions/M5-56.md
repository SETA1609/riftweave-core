# M5-56 A monster's effects, and the shields skill

Date: 2026-11-15
Modified: 2026-11-15

- **Decision:** a monster's list of applied effects is `effects`, the name a spell uses for the
  same `appliedEffect` list, so `abilities` names only the eight attributes. The shield skill is
  `shields` (`core:skill/shields`, label Shields), so `block` is only the reaction, and a bonus to
  blocking is a modifier on `shields`. **[V 2026-11-15, `validate.py`, the unit tests, and
  `go test ./...`, with a new combat vector]**
- **Why `shields` and not renaming the action:** the combat skills name what you use (`blades`,
  `bows`, `crossbows`), and the reaction kinds name what you do (`evade`, `block`), which the
  contract, the frontend, and the play CLI already send.
- **Difference from the issue:** none beyond the split from M5-37; the helper
  `damaging_abilities` in `monster_reference.py` became `damaging_effects`.
- **Risk:** breaking for data that names `core:skill/block` or a monster's `abilities`, and for a
  stored actor whose `skills` hold `block`; marked in the changelog. No migration of saves is
  written, since sessions are pre-1.0. **[A]**
