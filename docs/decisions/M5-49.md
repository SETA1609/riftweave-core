# M5-49 Core skills for a lighter tabletop sheet

Date: 2026-11-12

- **Decision:** two sheets on one rule set ([progression.md](../core/progression.md#two-sheets-one-rule-set)). The core rule is *track only what you raise*: a sheet writes the skills a character raised, and any other reads `skill_start`. The grouped sheet is a variant a table picks per campaign. [V 2026-11-12, `progression` vectors in Python and Go]
- **Decision:** 20 groups in `skill_groups/core.json`: Melee, Ranged, Defense, Stealth, Social, Knowledge, Wilds, Craft, Athletics, Medicine, one group per magic color (nine groups of one, so a table plays only its colors), and Armor, untracked. That is the issue's proposal, with engineering, building, and repair in Craft as proposed. [V 2026-11-12, `test_skills`, `validate.py`]
- **Decision:** a group holds *ranks*, not a value. A member reads its own `skill_start` plus the group's ranks, so each member keeps its own attribute (a Melee rank raises STR blades and AGI piercing by the same point). A group value would have needed a group attribute, and blades and piercing do not share one. [A]
- **Decision:** the cost. One group rank costs the skill cost (`normal` 2 or `tag` 1) times `ceil(members / members_per_step)`, with `members_per_step` 2 in data. A one- or two-skill group costs one skill's price, Melee and Ranged (4) twice, Craft (7) four times. The member-count price would make the grouped sheet only bookkeeping and a 7-skill group unaffordable, and a flat multiplier would make the one-skill magic groups worse than a full sheet. Tagging tags groups. [A]
- **Decision:** the cap: a group rank is not bought past `skill_cap` on its highest member, which the caller passes as `skill`, as `spend` already takes the current value. An untracked or unknown group is refused. [V 2026-11-12]
- **Why:** owner request, 2026-11-12: a newcomer should play without tracking 44 skills, and a game still tracks every one.
- **Open:** whether a background's skill bonus adds on a grouped sheet: the `read_skill` op reads start plus ranks only, and a caller that wants the bonus adds it. Moving from a grouped to a full sheet writes each tracked member's value. [A]
- **Risk:** a group rank buys more total skill than a full-sheet rank (Melee: 4 skills for 2 skills' price). A grouped character is broader than a full-sheet one at the same level; the balance pass (M5-09) should compare them.
