# PO_S20_10_template-grant-answer Record who may take a character template

Date: 2026-11-20

- **Decision** (owner answer, 2026-11-20): taking a character template is a GM or game-event matter.
  - **Rules as written:** a player cannot pick a template, and it is not a level-up choice. The GM grants it through a story or game event.
  - **Outside the rules:** the app has a checkbox, off by default, so someone can build a supposed character with a template (a GM's NPC, a one-shot, a what-if build).
- **Assumed** [A], for GD_S20_05's spec step to confirm:

  - A held template records how it came (`granted` or `outside_rules`), so the sheet shows a character built outside the rules.
