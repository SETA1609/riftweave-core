# M5-27 One way to compose a row

Date: 2026-11-10

- **Decision:** a composed row is a base, then layers in order, then overrides, then the row's own
  identity. Spec: `docs/core/composition.md`. **[V 2026-11-10, `test_composition.py`]**
- **Why:** monsters and equipment each had a merge, and M3-09 and M3-10 would have added more.
- **Check:** a hash of every resolved monster, weapon, armor, and accessory was the same before
  and after. **[V 2026-11-10]**
- **Open:** the Go loader reads the few fields it needs directly; it does not build full rows.
