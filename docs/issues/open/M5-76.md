#### M5-76 A development branch takes every merge, and main takes only development
- Status: review
- Priority: high
- Needs: —
- Modified: 2026-11-17
- Do: Owner request, 2026-11-17: `close-merged-issue.yml` has failed on every merge since it was added (0 successful runs of 83 [V 2026-11-17, the Actions API]), so merged issues stayed in `docs/issues/open/` with `Status: review`. The cause: `main` is protected for everyone but admins, and the workflow pushes its closing commit to `main` with `GITHUB_TOKEN`, which the protection rejects. The close step took 82 s, the length of the script's five push attempts with their waits; the tool closes an issue correctly when run locally. [V 2026-11-17] The run logs need a login and were not read. [U]
  - **The fix, owner's choice:** a `development` branch. Every issue branch starts from it and every pull request merges into it; the workflows that commit after a merge push there. `main` is protected so that only `development` merges into it, at a release. No token is needed.
  - **Workflows:** `close-merged-issue.yml` runs on pull requests closed into `development`; `changelog-fragments.yml` checks pull requests into `development` (a release pull request from `development` has no issue of its own); `rebase-open-branches.yml` runs on push to `development` and, through `main-branch = "development"` in `tools/devops/pyproject.toml`, rebases the pull requests that target it. Validation and the frontend CI already run on every push and pull request; Pages still deploys from a `v*` tag.
  - **Docs:** AGENTS.md, CONTRIBUTING.md (a Branches paragraph), `docs/issues/README.md`, and `docs/onboarding/README.md` say to branch from and target `development`.
  - **Cleanup:** the 17 issues that merged while the workflow failed move to `docs/issues/done/` with their `Merged:` lines, run with the same `close-merged-issue` command and each pull request's number and merge date: APP-10, APP-14, APP-15, APP-16, APP-23, APP-37, M3-14, M3-18, M3-25, M3-27, M5-37, M5-51, M5-55, M5-56, M5-57, M5-68, M5-69.
