#### M5-78 Perk skill bonuses: two skills or +10, an extra tag skill, and a skill-point ladder
- Status: todo
- Priority: medium
- Needs: M5-67
- Modified: 2026-11-18
- Do: Owner request, 2026-11-18: skills grow mainly by the points spent at every level-up and by `fortify_skill` from potions, food, and enchanted equipment, so a perk's skill bonus must be worth a perk.
  - **The rule.** A perk may add to skills only if it adds to **two or more skills**, or adds **at least +10** to one. A +10 matters most to a low-INT character, whose level-up pool (`5 + INT × 2`, progression/core.json) is small. Written in docs/modules/progression.md (what a perk emits); `test_perks.py` fails on a perk that adds less than +10 to a single skill. A negative skill modifier that is a drawback (`berserker`, −10 Evasion) is not a bonus and stays allowed [A]. A perk that only unlocks something needs no modifier (M3-24).
  - **Rows that break it today** (one skill at +5): `summon_dire`, `summon_elder`, `summon_ancient` (Orange Magic), `commanding_summons_magic` (Persuasion), `commanding_summons_physical` (Intimidation), `bardic_inspiration`, `bardic_anthem` (Persuasion), `skalds_war_chant`, `skalds_saga` (Intimidation). Each drops the bonus, raises it to +10, or adds a second skill, decided per row in the spec step [A]; the description text follows. The +10 single-skill perks (`scholar`, `locksmith`, `tracker`, and the rest) already meet the rule.
  - **An extra tag skill.** A new perk adds one tag skill, once (`tag_skills` +1, `ranks: 1`), the perk counterpart of the `genius` creation trait and `human_versatility`. Level gate by the tier spacing (ungated, Lv6, 12, 18, 24) [A]; the name is original.
  - **Tag skills stack** (owner 2026-11-18): the 3 at creation, plus a creation trait (`genius`), plus the perk, is 5; a human with `human_versatility` reaches 6. The origins already allow it: `trained` (perks, creation traits) and `innate` (racial traits) both stack by `add`, so nothing caps the count. The `tag_skills` target's description ("added at character creation") changes to cover a perk bought later. A skill tagged at a later level costs `skill_cost.tag` (1 point per rating, 1:1) from the moment it is tagged; points already spent on it at the normal cost (2:1) are not refunded and the rating stays as it is (owner 2026-11-18). `tag_skills` is `pending`: the build reference applies it, and a progression vector pins 3 + trait + perk = 5.
  - **A skill-point ladder, three tiers.** `quick_learner` (+2 skill points per level, INT 7, ungated) becomes tier 1 of a chain; two new perks follow, each needing the one before, at Lv6 and Lv12 or Lv12 and Lv18 [A], each adding +2 more per level [A], so the ladder gives +6 at the top. Its INT 7 gate is lowered (owner 2026-11-18), because the ladder helps low-INT characters most: INT 5 (owner 2026-11-18), the base value, so any character with at least average INT can take it. Names are original. Tiers stack: tier 2 adds to tier 1, unlike summon power, where the latest replaces.
  - **Wire the target.** `skill_points_per_level` is `pending` in modifier_targets/core.json: no reference applies it yet (build_reference.py applies only `skill_point_pool`). The level-up step adds it to each level's pool, in Python and Go, and a progression vector pins it, which clears `pending`. Order against `skill_point_pool` (Gifted's ×0.9): the add before the multiply, as docs/core/modifier.md stacks them [A].
  - **Balance is later** [U]: the ladder stacks with the creation traits (`gifted` ×0.9 pool, `genius` −15 starting points for a tag skill) and with the new tag skill perk. M5-50 (skill and damage pacing) checks the totals over thirty levels.
  - **Planned issues follow the same rule:** M3-21 (bonded summoner) lists "a bonus on the caster's skills" as a starting point; its spec meets the two-skills-or-+10 rule.
