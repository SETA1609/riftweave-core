A generator (`ruleset/scripts/data_flowcharts.py`, beside `data_model_diagram.py`) writes `docs/core/perk-ladders.md` and `docs/core/formula-trees.md` from the rows, with a drift test like M5-57's. **Perk ladders:** a `graph LR` per perk family (block, dodge, summoning, bard and skald, the stealth line, …), one node per perk with its level and its skill and attribute gates, an edge per perk prerequisite (a ranked one labelled with its rank, M3-14), grouped by the feature `category` [A]. It shows at a glance where a ladder ends early, the gaps the suggested builds found (M5-47, M5-60, M5-61), and perks no ladder reaches. **Formula trees:** a `flowchart TB` per formula tree (`combat/pipeline.json`'s bands and multipliers, `progression`'s `xp_to_reach` and `skill_points`, `formulas/*.json`), one node per operation and leaf, so a formula is read as a picture, not as nested JSON. Each page says it is generated and how to regenerate it. GitHub renders Mermaid, so no tool is installed.
