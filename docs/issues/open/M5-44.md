#### M5-44 Weight has a neutral unit
- Status: todo
- Priority: low
- Needs: —
- Do: Owner request, 2026-11-11: weight needs what distance and time already have, a neutral unit in the data and one conversion for reading aloud. Distance is units of one square, 1.5 m ([contract.md](../../core/contract.md#distance)), and time is seconds, with a turn of 5 seconds (`seconds_per_turn`). Weight is written today as pounds: `weight` on equipment says "Weight in pounds" in `equipment.schema.json`, the `carry` row in `derived/core.json` and `docs/core/derived.md` say pounds, and so do `attributes.md`, `armor.md`, and `character-creation.md`. Define a neutral **weight unit** and write every `weight`, `weightFactor` result, and carry limit in it. Proposal: keep today's numbers, so no row changes, and read one weight unit as 0.5 kg (500 g) [A]; a pound is 0.454 kg, so the old reading moves by about 10%. Write the conversion once, next to distance, with kilograms and grams, and note that nothing stores it. Replace every "pound" and "lb" in the schemas and docs. The naming rules in `CONTRIBUTING.md#naming` give `duration_rounds`, `range_meters`, and `weight_kilograms` as examples of a unit in a name, against the neutral units; rewrite that rule so a name carries a unit only when it is not the neutral one (units, seconds, weight units).
