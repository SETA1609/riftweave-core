### M5-73 Third normal form: an override lists only what differs
- Changed: an override object merges field by field into its base's, in Python and Go; `{"$replace": value}` replaces a field whole. **Breaking** for consumers that merge overrides themselves.
- Removed: 119 override and subrace values equal to what the row inherits; every merged row is unchanged.
- Added: integrity gate 5, which fails an override or subrace field equal to what it inherits.
