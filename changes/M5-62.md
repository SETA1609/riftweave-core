### M5-62 One project version, and a release that tags it
- Added: `VERSION` (`0.1.0`), the one project version; the Go core embeds it, and a test fails when the core, `frontend/package.json`, or the author manifest disagree.
- Added: `.github/workflows/release.yml` and `ruleset/scripts/release_check.py`: a `v*` tag is released only when it matches `VERSION`, `CHANGELOG.md` has its section, and every removed key is marked breaking.
- Changed: `frontend/package.json` says `0.1.0`; the release steps are in `CONTRIBUTING.md#releasing`.
