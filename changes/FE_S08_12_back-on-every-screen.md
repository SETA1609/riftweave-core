### FE_S08_12_back-on-every-screen A Back button on every screen
- Added: a screen header on every screen but the home page, with the screen's title and Back to its parent menu from the menu tree, also when the screen was opened by its URL; Esc does the same unless a field or a dialog has focus; character creation asks before leaving with changes no character was created from.
- Changed: the menus no longer end with a Back card; the screen header's Back replaces it.
