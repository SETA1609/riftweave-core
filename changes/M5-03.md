- Changed: the toolchain and agent containers run through `devops-tools container`, configured by `[tool.devops-tools.container]` in `tools/devops/pyproject.toml`; every shim in `scripts/` is one call to it; `container/Dockerfile` builds on the devops-tools base image.
- Removed: the local `devops` CLI and its tests, `container/agent.Dockerfile`, and `container/entrypoint.sh` (breaking for anyone calling `devops` directly).
- Changed: the toolchain Python is 3.13.12 (was 3.13.18), the base image's; the pip cache volume is a uv cache volume, `riftweave-uv-cache`.
- Added: `scripts/devcontainer-image.sh` builds the agent image for the devcontainer and tags it `riftweave-agent:devcontainer`.
